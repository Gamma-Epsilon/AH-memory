# Проект АГ-памяти

Проект посвящен вычислительному исследованию ассоциативно-гетероархической памяти когнитивного агента. В упрощенной модели память рассматривается как гиперграфовая структура, где бинарные признаки объединяются ассоциативными гиперсвязями, а история фиксирует акты запоминания и восстановления.

Главная задача проекта - проверить, могут ли методы эволюционной оптимизации находить такие топологии гиперграфа, которые обеспечивают более точное восстановление информации, лучшую устойчивость к шуму и более надежное различение близких образов по сравнению с простыми и случайными топологиями.

В ходе экспериментов будут оцениваться качество восстановления, устойчивость к искажениям, различение похожих паттернов и структурная сложность памяти. Оптимизация будет направлена на поиск компромисса между высокой функциональной эффективностью и компактностью гиперграфовой структуры.

Перед запуском кода можно установить недостающие библиотеки из файла зависимостей.
