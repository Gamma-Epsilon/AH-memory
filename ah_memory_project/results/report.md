## Основной эксперимент

Сгенерирован набор бинарных паттернов для проверки АГ-памяти. Использовано 32 вершин, 24 паттернов и 3 кластера. Доля активных битов составила 0.25. Параметр внутрикластерной близости равен 6.

Межкластерное расстояние контролировалось по расстоянию Хэмминга. Исходный целевой порог равен 18, фактически использованный порог равен 16, нижняя допустимая граница равна 12. Порог был снижен: Ограничение, связанное с фиксированной долей активных битов. Фактически использованный порог остался выше нижней допустимой границы.

Для различения близких паттернов использован порог 6. Этот порог взят из конфигурации генерации данных и сохранён в таблицах решений.

Пул гиперребер содержит 40 кандидатов. Минимальная кратность равна 2, максимальная кратность равна 4.

NSGA-II выполнен с популяцией 12 и числом поколений 4. Использовано работников: 2. На Парето-фронте получено 11 решений.

Созданы таблицы: tables/patterns.csv, tables/candidate_pool.csv, tables/pareto_solutions.csv, tables/nsga_objectives.csv, tables/baseline_metrics.csv.

Краткая сводка по Парето-фронту: лучшая точность восстановления 0.969, лучшая устойчивость 0.969, лучшее различение близких паттернов 0.936, минимальная структурная сложность 0.325.

Краткая сводка по базовым топологиям: dense: точность 0.952, устойчивость 0.952, различение 0.859; frequency: точность 0.952, устойчивость 0.952, различение 0.859; pairwise: точность 0.957, устойчивость 0.957, различение 0.872; random: точность 0.986, устойчивость 0.986, различение 0.949.

Предварительные выводы по гипотезам: H1 — Пока не подтверждается. H2 — Требует анализа Парето-фронта и структурных диапазонов. H3 — Пока не подтверждается.

## Расширенный эксперимент

Расширенный запуск выполнен на одном seed. Из-за времени выполнения около 9,6 минуты дополнительные seed целесообразно запускать отдельной серией после фиксации параметров.

Сгенерированы данные с 32 вершинами, 30 паттернами и 3 кластерами. Порог близости для близких паттернов равен 6. Межкластерный целевой порог равен 18, фактически использованный порог равен 16.

По сравнению с умеренным запуском увеличены число поколений, размер популяции, размер пула гиперребер и число случайных базовых топологий. Использованы параллельные вычисления.

На Парето-фронте получено 12 решений. Лучшая точность восстановления равна 0.969, лучшая устойчивость равна 0.969, лучшее различение близких паттернов равно 0.904.

По сравнению с умеренным запуском лучшая точность восстановления осталась практически на том же уровне, устойчивость также осталась сопоставимой, а лучшее различение близких паттернов снизилось. Лучшая случайная базовая топология в расширенном запуске по-прежнему не уступила Парето-фронту по максимуму точности и различения.

Среднее число гиперребер на Парето-фронте равно 25.083, средняя плотность равна 0.358, средняя кратность гиперребра равна 2.214.

Структурно расширенный Парето-фронт использует больше гиперребер в среднем, но имеет меньшую среднюю плотность относительно увеличенного пула кандидатов. Средняя кратность гиперребра почти не изменилась.
