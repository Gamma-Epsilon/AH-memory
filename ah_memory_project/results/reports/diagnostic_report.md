Лучшее решение по точности имеет точность 0.969. Лучшее решение по устойчивости имеет устойчивость 0.969. Лучшее решение по различению имеет различение 0.904.

Сравнение показывает, что Парето-фронт не превосходит лучшую случайную базовую топологию по максимуму точности и различения.
