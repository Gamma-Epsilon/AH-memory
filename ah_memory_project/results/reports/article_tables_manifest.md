# Описание таблиц для статьи

## Базовые топологии

1. Источник данных: `results/tables/final_seed_*_baseline_metrics.csv`.
2. Содержание: метрики базовых топологий, использованных для сравнения с Парето-решениями NSGA-II.
3. Рекомендуемое название: Таблица N. Базовые топологии, использованные для сравнения с результатами оптимизации.

## Параметры финальной серии

1. Источник данных: `results/reports/final_summary.md`, `results/reports/final_summary.csv`, `results/reports/final_seed_*_summary.json`.
2. Содержание: параметры финальной постановки, число паттернов, число вершин, число кластеров, порог близости, уровни шума и пропусков, размер пула гиперребер, бюджет NSGA-II, число случайных baseline и список начальных состояний.
3. Рекомендуемое название: Таблица N. Параметры финальной серии вычислительного эксперимента.

## Сводные характеристики по seed

1. Источник данных: `results/reports/final_summary.csv`.
2. Содержание: сводные метрики по начальным состояниям, включая accuracy, robustness, H3 index accuracy, H3 bit accuracy, число близких пар, число H3-тестов и размер Парето-фронта.
3. Рекомендуемое название: Таблица N. Сводные характеристики финальной серии по начальным состояниям генератора случайных чисел.

## Итоговая проверка гипотез

1. Источник данных: `results/reports/final_summary.csv`, `results/reports/final_summary.md`, `results/report.md`.
2. Содержание: итоговые статусы H1, H2 и H3 относительно среднего и лучшего baseline, а также структурные диапазоны лучших топологий.
3. Рекомендуемое название: Таблица N. Итоговая проверка исследовательских гипотез.

## Парето-решения финальной серии

1. Источник данных: `results/tables/final_seed_*_pareto_solutions.csv`.
2. Содержание: решения Парето-фронта по каждому начальному состоянию, включая accuracy, robustness, H3 index accuracy и структурные характеристики топологий.
3. Рекомендуемое название: Таблица N. Парето-решения финальной серии вычислительного эксперимента.

## Все оценки NSGA-II

1. Источник данных: `results/tables/final_seed_*_nsga_objectives.csv`.
2. Содержание: все оценённые топологии NSGA-II по каждому начальному состоянию.
3. Рекомендуемое название: Таблица N. Оценённые топологии NSGA-II в финальной серии.
