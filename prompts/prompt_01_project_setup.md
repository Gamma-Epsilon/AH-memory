# Промпт 01. Создание структуры проекта

Прежде чем выполнять код, внимательно прочитай файлы `prompts/project_context.md` и `prompts/ah_memory_formalism.md`, чтобы понять научную постановку и структуру АГ‑памяти. Этот промпт задаёт создание минимальной структуры проекта и подготовку окружения для экспериментов. 

## Задание

1. Создай корневую папку проекта (например, `ah_memory_project`). Внутри неё размести директории:
   * `src/` — для исходного кода.
   * `results/` — для сохранения таблиц, рисунков и отчётов. Внутри `results/` создай подпапки: `tables/`, `figures/`, `reports/`. **Также создай пустой файл `report.md` прямо в каталоге `results/`**. Этот файл будет служить общим отчётом, который нужно будет заполнять по мере выполнения экспериментов. На этом этапе файл должен быть пустым, и Codex не должен его модифицировать до тех пор, пока не начнут выполняться эксперименты.
   * `tests/` — для модульных тестов.
   * `scripts/` — для вспомогательных исполняемых скриптов (например, запуска эксперимента). 
   * `prompts/` — копия текущей папки с контекстом и промптами (переносить файлы не нужно, просто создай пустую папку или укажи, что контент уже имеется).
2. В папке `src/` создай Python‑пакет (например, `ah_memory/`) с файлом `__init__.py`. Этот пакет будет содержать модули, описывающие память и связанные процессы.
3. Создай файл `requirements.txt`, куда впиши библиотеки, необходимые для работы программы: `numpy`, `pandas`, `scipy`, `matplotlib`, `pymoo` и `pytest`. Укажи, что при запуске кода можно автоматически установить недостающие библиотеки.
4. Создай файл `README.md` с кратким описанием цели проекта на основе `prompts/project_context.md`. Описание должно быть лаконичным и понятным: что такое АГ‑память, какие задачи стоят, что будет оптимизироваться. Не вставляй в README код или имена переменных. 
5. Подготовь начальную структуру файлов в `src/` (пока они могут быть пустыми) согласно будущим промптам: модули для конфигурации, гиперграфа, генерации паттернов, памяти, метрик, оптимизации, базовых топологий, визуализации и статистики. Названия файлов должны отражать назначение модулей.
6. Убедись, что структура минимальна и понятна, без лишних папок, сложных конфигураций и внешних зависимостей. 

## Формат отчёта

После выполнения задания подготовь **отчёт**, придерживаясь следующего шаблона (на русском языке, без вставки кода или названий переменных):

```
ОТЧЁТ ПО ПРОМПТУ №01

1. Что сделано:
   - … (описать основные действия: какие папки созданы, какие файлы подготовлены)
2. Какие файлы созданы или изменены:
   - … (перечислить новые файлы и директории)
3. Как запустить проверку:
   - … (при необходимости описать, как проверить, что структура создана корректно)
4. Результат проверки:
   - … (кратко сообщить, что структура соответствует заданию)
5. Возможные проблемы:
   - … (если есть замечания или сложности)
6. Что нужно уточнить перед следующим шагом:
   - … (если есть вопросы к пользователю)
7. Отклонения от промпта:
   - … (если есть любые отличия от задания; если их нет, написать «Отклонений нет»)
```

Пиши отчёт в указанном формате. Не вставляй в отчёт код, имена переменных или английские слова, если это не требуется. Комментарии в коде должны быть на русском языке.
