# Промпт 06. Настройка многокритериальной оптимизации (NSGA‑II)

На данном этапе необходимо подготовить всё для эволюционного поиска оптимальных топологий гиперграфа с использованием алгоритма NSGA‑II. Запомни, что цель оптимизации — компромисс между качеством восстановления, устойчивостью, различением и компактностью структуры.

## Задание

1. Создай в каталоге `src/ah_memory/` модуль `optimization.py`. В нём реализуй класс, наследующийся от `pymoo.core.problem.ElementwiseProblem` (или аналогичного базового класса), который описывает задачу многокритериальной оптимизации:
   - **Переменные.** Геном должен быть бинарным вектором длины `M`, где `M` — количество гиперребер в пуле. Каждый бит указывает, включено ли гиперребро в топологию.
   - **Ограничения.** Задай минимальное и максимальное число выбираемых гиперребер (параметры берутся из конфигурации). Если геном нарушает эти пределы, оценивай его хуже (например, добавляя штраф к целям).
   - **Функция _evaluate().** Для каждого генома выполняй:
     1. Преобразуй бинарный вектор в конкретную топологию (подмножество гиперребер).
     2. Оцени память на этой топологии с помощью `evaluate_memory` (из предыдущего промпта), получив функциональные и структурные метрики.
     3. Сформируй четыре цели для минимизации:
        * **f1 = 1 – точность восстановления.**
        * **f2 = 1 – устойчивость к шуму.**
        * **f3 = 1 – способность различать близкие паттерны.**
        * **f4 = сложность.** Сложность должна быть комбинацией нормированного числа гиперребер, плотности, средней кратности и разброса степеней. Точная формула может быть линейной комбинацией этих факторов; важно, чтобы она уменьшалась при уменьшении размера и упорядоченности гиперграфа.
     4. Сохраняй дополнительные метрики в атрибуте `out["metrics"]` или внутреннем массиве, чтобы затем построить таблицы и графики.
2. Реализуй функцию `run_nsga2(patterns, tests, candidate_pool, configs)`, которая:
   - Принимает обучающие паттерны, тесты, пул кандидатов и конфигурации (например, размеры популяции и число поколений).
   - Инициализирует задачу оптимизации.
   - Настраивает инструменты `pymoo`: бинарную инициализацию популяции, оператор кроссовера (можно использовать двуточечный), оператор мутации (побитовый), селекцию NSGA‑II. 
   - Запускает оптимизацию, используя параллельные вычисления для ускорения (в `pymoo` можно настроить `n_processes` при необходимости), сохраняя результаты.
   - Возвращает объект результата `pymoo` и таблицу (например, `pandas.DataFrame`) с информацией о метриках для всех решений на Парето‑фронте.
3. Добавь возможность настройки параметров алгоритма через конфигурацию (`population_size`, `n_generations`, `crossover_probability`, `mutation_probability`, `eliminate_duplicates`), как было указано в проектном контексте. Значения по умолчанию должны обеспечивать научный (не учебный) эксперимент, но оставаться разумными с учётом времени выполнения.
4. Убедись, что код прост для понимания: не добавляй лишних обёрток, асинхронных механизмов, логирования, если это не требуется. Одновременно задокументируй методы на русском языке.
