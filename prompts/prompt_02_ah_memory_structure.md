# Промпт 02. Реализация структуры АГ‑памяти

Перед началом работы ещё раз ознакомься с `prompts/project_context.md` и `prompts/ah_memory_formalism.md`. Этот промпт посвящён реализации основных модулей упрощённой АГ‑памяти, строго соответствующей формализации Душкина и описанной в проектном контексте. Важно реализовать структуру так, чтобы она была понятна, проста в поддержке и не содержала лишних усложнений.

## Задание

1. В каталоге `src/ah_memory/` создай модуль (файл) для каждой из следующих компонент:
   - **Множество абстрактных символов (S)**. Представляет пространство признаков. В упрощённой модели символы — это просто индексы в бинарном векторе. Создай класс или структуру, которая хранит размерность и, при необходимости, может выдавать случайные паттерны (но это будет реализовано в следующем промпте).
   - **Слой знаний (K)**, объединяющий гиперсети общих и частных знаний. Это набор гиперребер (ассоциаций) между символами. Каждое гиперребро хранит список индексов символов и вес. Нужно предусмотреть методы для:
     * добавления гиперребер,
     * вычисления и обновления весов по частоте совместной активации в паттернах,
     * получения статистической информации (например, список гиперребер, их размеры).
   - **Историческая сеть (H)**. Реализуй структуру, которая хранит список эпизодов вида: исходный паттерн, искажённый вход, восстановленный паттерн, оценка. Каждый раз при извлечении памяти должен автоматически добавляться новый эпизод. Реализуй методы для добавления эпизода и, при необходимости, для выборки истории (для статистики).
   - **Фокус активации (F)**. Создай класс или набор функций, которые будут использоваться для оценки и восстановления паттернов. Он должен учитывать совпадение битов, активность гиперребер (по их весам) и штраф за сложность (введён в проектном контексте). Этот фокус не является сложной динамической системой; он реализует вычисление числовой оценки для каждого сохранённого паттерна и выбирает наилучший.
   - **Класс памяти (AHMemory)**. Объединяет все предыдущие компоненты. Содержит методы:
     * `fit(patterns)`: принимает обучающую выборку паттернов, строит веса гиперребер на основе частоты совместной активации и сохраняет паттерны;
     * `record(pattern)`: добавляет новый паттерн в память;
     * `retrieve(query)`: возвращает индекс наиболее подходящего паттерна и его восстановленную версию, используя фокус активации;
     * `retrieve_batch(tests)`: обрабатывает набор тестов (искажённых входов) и возвращает результаты;
     * `add_episode(original, distorted, result, score)`: записывает эпизод в историю.
   Класс должен использовать компоненты `S`, `K`, `H` и `F`, чтобы отражать структуру \(AH = \langle S,C,P,H,L\rangle\) в упрощённом виде.
2. Все классы и функции должны содержать краткие комментарии на русском языке, объясняющие назначение и принцип работы. Не упоминай конкретные переменные, которые будут использоваться в других модулях. 
3. Структуры данных должны быть как можно более простыми: избегай сложных паттернов проектирования, фабрик, генераторов. Достаточно классов и простых списков/словари/массивов.
4. Не реализуй генерацию паттернов, построение пула гиперребер или оптимизацию на этом этапе. Эти задачи выполняются в других промптах.
5. Следи за тем, чтобы названия классов и методов отражали смысл, исходя из модели Душкина: например, `SymbolSet`, `KnowledgeHypergraph`, `EpisodeMemory`, `ActivationFocus`, `AHMemory`. Это поможет читать код и соотносить его с теорией.
