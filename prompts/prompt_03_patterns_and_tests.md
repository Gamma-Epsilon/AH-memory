# Промпт 03. Генерация паттернов и тестовых входов

В этом этапе необходимо реализовать генерацию обучающих паттернов и искажённых входов для тестирования памяти. Пожалуйста, придерживайся инструкций из `prompts/project_context.md` и не добавляй лишние сложности. 

## Задание

1. В модуле `src/ah_memory/patterns.py` реализуй функции для генерации бинарных паттернов:
   - **Генератор кластерных паттернов.** Реализуй функцию для создания набора бинарных векторов (паттернов) заданной длины. Паттерны должны быть сгруппированы в кластеры: внутри кластера они отличаются на небольшое число битов (указывается параметром), а между кластерами — на большее расстояние. Доля активных битов (единиц) должна соответствовать параметру из конфигурации. Функция должна возвращать массив паттернов, которые будут использоваться для обучения и тестирования памяти.
   - **Коррупция паттернов (искажение).** Реализуй функцию, которая принимает паттерн и два уровня: процент инверсий (замены 0 на 1 и наоборот) и процент пропусков (замены битов на неизвестное значение, например, −1). Эта функция должна возвращать искажённый вход для теста. Уровни шума и пропусков берутся из конфигурации.
   - **Подготовка тестов.** Реализуй функцию, которая на основе набора исходных паттернов и списков уровней шума/пропусков создаёт список тестов. Каждый тест должен содержать: индекс исходного паттерна, исходный паттерн, искажённый вход, уровень шума и уровень пропусков. Количество тестов на один паттерн задаётся параметром конфигурации.
   - **Поиск близких пар.** Реализуй вспомогательную функцию для поиска пар паттернов, отличающихся на небольшое число битов (внутри кластера). Это пригодится для метрик различения.
2. Для управления параметрами (число паттернов, размерность, доля активных битов, число кластеров, степень сходства внутри кластера, уровни шума и пропусков, количество испытаний) создай dataclass‑конфигурацию (если она ещё не создана) в отдельном модуле `config.py` и используй её в этих функциях. Конфигурация должна хранить seed для воспроизводимости.
3. В модуле `tests/` добавь несколько простых тестов, проверяющих:
   - Правильный размер сгенерированных паттернов и распределение активных битов;
   - Что искажение действительно меняет биты и добавляет пропуски;
   - Что функция поиска близких пар корректно находит похожие паттерны.
4. Все функции должны быть задокументированы комментариями на русском языке, объясняющими их назначение и параметры. Не используй в документации названия переменных, которые появятся в других частях проекта.
