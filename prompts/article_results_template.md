# Шаблон отчёта о результатах эксперимента

Этот файл представляет структуру **отчёта о результатах эксперимента**. Он предназначен для фиксации полученных данных, метрик и проверки гипотез **без использования научного стиля и без литературного обзора**. 

> **Важно.** Шаблон нужен для пользователя или ассистента, который будет составлять итоговую статью. **Codex не должен писать этот отчёт самостоятельно** и не должен заполнять его литературным содержанием. Его задача — сформировать результаты (таблицы, графики, файлы). Статья будет написана отдельно.

Заполнять разделы следует только числовой и фактологической информацией: перечислением параметров эксперимента, результатами метрик, статусами гипотез. В отчёте не должно быть кода, ссылок на статьи, авторов или научных рассуждений. Отчёт может быть оформлен в простом markdown‑формате.

## Структура отчёта

### 1. Параметры эксперимента
Список всех параметров, используемых в эксперименте: число вершин, число паттернов, параметры генерации паттернов (доля активных битов, количество кластеров, расстояния), размеры пула гиперребер, параметры эволюционного алгоритма (размер популяции, число поколений, вероятности мутаций и кроссовера), размеры топологии (минимальное и максимальное число гиперребер) и уровни шума/пропусков.

### 2. Результаты метрик
Табличное представление основных функциональных и структурных метрик для оптимизированных топологий и базовых стратегий. Укажите средние значения точности восстановления, устойчивости, различения и сложность топологии. В отдельной строке можно указать лучшую топологию по каждой метрике.

### 3. Проверка гипотез
Простой список с указанием, подтверждается или опровергается каждая из гипотез H1–H3 на основе статистических тестов. Например: «H1 — подтверждена, NSGA‑II показал значимое превосходство по точности и устойчивости над случайными топологиями (p < 0.05)».

### 4. Ссылки на файлы
Перечень всех созданных файлов с кратким описанием содержимого: CSV‑таблицы, графики, файлы статистических результатов. Например:

- `tables/pareto_solutions.csv` — метрики решений на Парето‑фронте.
- `figures/pareto_accuracy_complexity.png` — график зависимости точности от сложности.
- `reports/hypothesis_summary.txt` — текстовый файл с результатами проверки гипотез.

### 5. Краткие выводы
Несколько предложений, суммирующих основные наблюдения по данным: какие параметры гиперграфа оказались оптимальными, какие метрики улучшились по сравнению с базовыми топологиями, какие гипотезы подтверждены. Избегайте научного стиля и литературных рассуждений.
