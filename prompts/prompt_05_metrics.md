# Промпт 05. Реализация метрик качества и структурных характеристик

На этом этапе необходимо реализовать набор функций, оценивающих качество работы памяти и структуру гиперграфа. Эти функции будут использоваться как цели оптимизации и для последующего анализа результатов.

## Задание

1. В модуле `src/ah_memory/metrics.py` реализуй функции для **функциональных метрик**:
   - **Средняя точность восстановления.** Доля совпавших битов между восстановленным и истинным паттерном, усреднённая по всем тестам. Игнорируй позиции, где входной паттерн содержит пропуски (−1).
   - **Точность полного совпадения.** Доля тестов, в которых восстановленный паттерн полностью совпал с истинным.
   - **Устойчивость к шуму.** Рассчитывай среднюю точность восстановления по всем комбинациям уровней шума и пропусков. Верни также таблицу (например, словарь) зависимости точности от уровня шума.
   - **Различение близких паттернов.** Вычисляй долю тестов, где исходный паттерн имеет близких соседей (найденных функцией поиска близких пар из прошлого промпта) и был восстановлен корректно.
   - **Частота путаницы.** Доля тестов, где система перепутала исходный паттерн с одним из его близких соседей.
2. Реализуй функции для **структурных метрик** гиперграфа:
   - **Количество гиперребер**, **средняя кратность** гиперребра, **плотность** (отношение числа гиперребер к размеру пула кандидатов).
   - **Степени вершин:** максимальная степень, средняя степень, дисперсия степеней, индекс Джини и энтропия распределения степеней.
   - **Гистограмма размеров гиперребер.** Верни распределение количества гиперребер различных размеров (например, словарь «размер» → количество).
3. Создай функцию `evaluate_memory(patterns, topology, tests, retrieval_config, candidate_pool_size)`, которая:
   - инициализирует объект памяти с заданной топологией;
   - проводит извлечение по всем тестам;
   - вычисляет все функциональные и структурные метрики, объединяет их в один словарь и возвращает для дальнейшего анализа.
4. Добавь модульные тесты в `tests/`, проверяющие корректность расчёта основных метрик на упрощённых примерах (например, проверка, что точность полного совпадения равна 1, если восстановление совпадает со всеми исходными паттернами).
5. Комментируй функции на русском языке, кратко поясняя назначение и параметры. Внутри функций избегай жёстких зависимостей от других модулей: функции должны принимать объекты, а не импортировать их сами, чтобы оставаться независимыми.
