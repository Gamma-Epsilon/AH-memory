# Промпт 04. Операции записи и извлечения в АГ‑памяти

Прежде чем приступить к оптимизации, нужно завершить реализацию операций записи и извлечения паттернов. Эти операции должны учитывать структуру гиперграфа и параметры конфигурации (например, коэффициенты для различных вкладов). Внимательно используй определения из `prompts/ah_memory_formalism.md`.

## Задание

1. **Запись в память.** Допиши метод `fit()` (или аналогичный) в классе памяти так, чтобы при передаче набора паттернов:
   - вычислялись веса всех гиперребер в слое знаний `K`. Вес гиперребра должен отражать, насколько часто все входящие в него символы совместно активны в обучающих паттернах. Можно использовать простое отношение: число совместных активаций делить на общее число паттернов. 
   - сохранялись исходные паттерны в памяти.
2. **Подсчёт оценочной функции.** Реализуй метод (например, `score_pattern`), который принимает искажённый вход и один из сохранённых паттернов и возвращает числовую оценку. Оценка должна учитывать:
   - **Совпадение битов.** Сравнивай только позиции, где вход известен (не равен −1). Доля совпадений умножается на коэффициент α (значение можно задать в конфигурации `RetrievalConfig`).
   - **Активность гиперребер.** Для каждого гиперребра в топологии, которое полностью содержится как во входе, так и в паттерне, добавляй вклад, пропорциональный его весу. Этот вклад умножается на коэффициент β из конфигурации.
   - **Штраф за сложность.** Введи штраф, пропорциональный размеру гиперграфа или суммарному числу гиперребер. Этот штраф умножается на коэффициент γ из конфигурации и вычитается из общей оценки. 
   Все коэффициенты α, β, γ должны быть параметрами конфигурации `RetrievalConfig`.
3. **Извлечение.** Реализуй метод `retrieve(query)`, который проходит по всем сохранённым паттернам, вычисляет для каждого оценку с помощью `score_pattern` и выбирает паттерн с максимальной оценкой. Метод должен возвращать индекс выбранного паттерна, восстановленный бинарный паттерн и, при желании, значение оценки. После восстановления добавь эпизод в историю `H`.
4. **Пакетная обработка.** Реализуй метод `retrieve_batch(tests)`, который принимает список тестов (как создано в предыдущем промпте) и возвращает список результатов: исходный индекс, индекс восстановленного паттерна, точность восстановления (доля совпавших битов) и отметку о полном совпадении. Это упростит вычисление метрик.
5. Все методы должны быть снабжены комментариями на русском языке, поясняющими их назначение и логику. Названия методов и классов должны быть ясными и связанными с формализмом АГ‑памяти.

```

   - …
3. Как запустить проверку:
   - … (например, описать простую проверку на корректность работы retrieve)
4. Результат проверки:
   - …
5. Возможные проблемы:
   - …
6. Что нужно уточнить перед следующим шагом:
   - …
7. Отклонения от промпта:

```

В отчёте описывай процессы на уровне концепций (вклад совпадений, вклад гиперребер, штрафы), избегая упоминания конкретных переменных и кода.
