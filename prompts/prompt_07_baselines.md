# Промпт 07. Реализация базовых топологий и сравнений

Для объективной оценки эффективности эволюционной оптимизации необходимо сравнить её результаты с простыми конструктивными стратегиями построения гиперграфа. Этот промпт посвящён созданию базовых топологий и функции, которая запускает их оценку.

## Задание

1. В модуле `src/ah_memory/baselines.py` реализуй функции, создающие и оценивающие несколько **базовых топологий** на основе пула гиперребер:
   - **Случайная топология.** Создай функцию, которая выбирает случайное подмножество гиперребер (размер подмножества задаётся параметрами минимальной и максимальной мощности). Повтори этот процесс несколько раз (`n_runs`) и вычисли метрики для каждого случая. Результаты должны возвращаться в виде таблицы (например, `pandas.DataFrame`), где каждая строка соответствует отдельному запуску.
   - **Частотная топология.** Функция должна выбрать гиперребра, наиболее часто встречающиеся в обучающих паттернах (по частоте совместной активации). Количество выбираемых гиперребер и критерий отбора берутся из конфигурации. Затем оцени полученную топологию.
   - **Парная топология.** Сформируй топологию, используя только гиперребра размера 2. Это фактически обычный граф. Для сравнения с гиперграфом оцени её.
   - **Плотная топология.** Создай топологию, содержащую большое количество гиперребер (например, максимальное допустимое число). Это позволит сравнить, как ведёт себя память при избытке связей.
2. Реализуй функцию `evaluate_baselines(patterns, tests, candidate_pool, configs)`, которая:
   - принимает обучающие паттерны, тесты, пул гиперребер и конфигурации;
   - создаёт каждую из базовых топологий;
   - инициализирует память с этой топологией, проводит извлечение и вычисляет метрики;
   - возвращает общую таблицу со всеми результатами.
3. Все функции должны быть снабжены комментариями на русском языке. Код должен быть простым и прозрачным. Используй уже реализованные функции для оценки (`evaluate_memory`), не дублируй код.
4. Добавь несколько тестов в `tests/`, чтобы проверить корректность работы базовых функций (например, что случайная топология действительно случайна, что частотная отбирает наиболее часто встречающиеся гиперребра).
